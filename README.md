# mambattu-dev/homebrew-tap

```sh
brew install --cask mambattu-dev/tap/orca      # stable
brew install --cask mambattu-dev/tap/orca@rc   # release candidates
```

`orca` is a signed fork build of [stablyai/orca](https://github.com/stablyai/orca), released from
[mambattu-dev/orca](https://github.com/mambattu-dev/orca). It installs as `Orca.app` and replaces an
upstream install; the in-app updater follows this fork's releases. Casks are bumped automatically
by the fork's release workflow.
